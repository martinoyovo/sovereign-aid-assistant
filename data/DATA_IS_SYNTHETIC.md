# ⚠️ This data is entirely synthetic

Every record in this directory is **fictional** and was generated for a software
demonstration. Nothing here describes a real person, family, household, location,
or event.

- All family names are invented.
- All region names ("Eastern Sector", "Northern Reach", "Western Basin",
  "Southern Delta") are fictional placeholders, not real places.
- All case IDs, dates, household sizes, and aid records are made up to exercise
  the application's features.
- The narrative field notes in `notes/` describe invented situations.

This dataset exists only to show how the **Sovereign Aid Assistant** queries and
reasons over local case data **without sending anything off the machine**. It must
never be confused with real humanitarian case data, and real case data should
never be committed to this repository.
