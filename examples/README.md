# Sample documents for the demo

Ready-made, **synthetic** field reports you can drag into the app's "Add a field
report" uploader during a demo. All three contain the same content in different
formats:

| File | Use it to show |
|------|----------------|
| `field-report-bridge-collapse.md` | Markdown upload (safest, recommended on stage) |
| `field-report-bridge-collapse.txt` | Plain-text upload |
| `field-report-bridge-collapse.pdf` | PDF upload (parsed to text locally) — this PDF is vetted and extracts cleanly |

## Suggested demo beat

1. In the left panel, click **"Add a field report"** and choose
   `field-report-bridge-collapse.md` (leave it as a standalone report).
2. Ask: **"Are there any protection concerns I should know about?"**

The agent's `search_notes("protection")` now surfaces the **bridge-collapse
report alongside the existing cases** — the three unaccompanied adolescents and
the urgent follow-up — proving the just-uploaded document is searchable, and that
it never left the machine.

> All content here is fictional and exists only to demonstrate the application.
> The `.pdf` was generated from the `.txt` for a reliable, known-good PDF upload.
